# 🔍 Fake News Detector

An AI-powered web app that detects whether a news article is real or fake!

## 🌐 Live Demo
[Click here to try it!](https://fake-news-detector2k26.streamlit.app/)

## 🚀 Features
- Paste any news article and get instant analysis
- AI gives a credibility score out of 10
- Explains reasons why it's fake or real
- Gives a short summary and advice

## 🛠️ Tech Stack
- Python
- Streamlit
- Groq AI (Llama 3.3)
- python-dotenv

## 📦 Installation
1. Clone the repo
2. Install dependencies
pip install -r requirements.txt
3. Add your Groq API key in `.env` file
GROQ_API_KEY=your-key-here
4. Run the app
streamlit run app.py
